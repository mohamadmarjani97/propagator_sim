# BioWet Mobile (React Native + Expo)

## Screens included in scaffold

- Onboarding + permissions + sign-in options
- Home dashboard
- Interactive map with layers and AI species prediction trigger
- Report a sighting flow with photo upload and status feedback
- Explore feed (observations, species pages, wetland detail cards)
- Profile with contribution stats and premium agency section
- Admin/expert dashboard

## Run

```bash
npm install
npm run start
```

## Design language

- Nature-inspired palette (greens, blues, earth tones)
- Rounded cards and low visual clutter
- Mobile-first layout optimized for hand-held operation
